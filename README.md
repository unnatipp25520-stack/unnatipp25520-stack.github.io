# Unnati Sharma — Premium Portfolio

Responsive portfolio with animated gradient typography, floating glass-style hero art, CSS-made project illustrations, scroll reveal animation, mobile navigation and clickable contact/social links.

## Preview
1. Download and extract `Unnati_Portfolio_Premium.zip`.
2. Open the folder and double-click `index.html`.
3. It opens in your browser. Internet is only needed for the optional Google Font.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository named `unnatipp25520-stack.github.io` (if that name is available).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save if the option appears.
4. Wait for GitHub Pages to publish. The expected URL is `https://unnatipp25520-stack.github.io/`.

## Important
Project buttons currently open your GitHub profile because individual project repository URLs have not been provided. After publishing each project repo, replace those three `href` values in `index.html` with the correct repository URLs.
